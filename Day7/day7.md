# My Claude Usage Strategy

## Recommended Primary Model

Claude Sonnet

## Why This Model Fits Me

Claude Sonnet provides the best balance of speed, reasoning, and quality for my daily work involving Python development, FastAPI, Generative AI learning, documentation, and research.

---

## When To Use Haiku

- Quick summaries
- Email drafts
- Documentation cleanup
- Fast responses

---

## When To Use Sonnet

- Python coding
- FastAPI development
- Learning GenAI
- Prompt engineering
- GitHub documentation
- Content creation

---

## When To Use Opus

- Deep research
- AI strategy
- Architecture design
- Complex reasoning
- Long-form analysis

---

## Recommended Effort Levels

### Low

- Quick summaries
- Rephrasing
- Notes

### Standard

- Coding
- Learning
- Documentation
- LinkedIn content

### High

- Debugging
- Technical design
- Architecture reviews

### Max

- Deep research
- AI strategy
- Long-term planning

---

## Biggest Mistakes To Avoid

- Using the most powerful model for every task
- Asking vague questions
- Not providing enough context
- Using Max effort for simple tasks

---

## Final Recommendation

If I could use only one model and one effort level for most of my work:

Model: Claude Sonnet

Effort: Standard

Reason:
Provides the best balance between quality, speed, and productivity for coding, learning, documentation, and research.

---

## Key Learnings

- Different Claude models serve different purposes.
- Model selection impacts productivity.
- Effort levels should match task complexity.
- Context improves output quality.
- Sonnet is the best daily-driver model for my workflow.
