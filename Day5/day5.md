# Day 5 - Context Engineering Challenge

## Prompt A (Without Context)

Prompt A generated a generic 30-day learning roadmap suitable for any beginner learner.

![Prompt A](promptA.png)

---

## Prompt B (With Context)

Context Provided:
- Current Situation: Professional
- Current Skills: React, Python, Azure
- Goal: Become an AI Engineer
- Available Time: 2 Hours per Day
- Experience Level: Intermediate
- Preferred Learning Style: Projects

Prompt B generated a personalized AI Engineer roadmap aligned with my skills and career goals.

![Prompt B](promptB.png)

---

## Comparison

![Comparison](comparison.png)

### 1. Which roadmap feels more personalized?

Prompt B (With Context) feels more personalized because it considers my skills, goal, available time, experience level, and preferred learning style.

### 2. Which roadmap would you actually follow?

Prompt B because it is aligned with my goal of becoming an AI Engineer and includes practical projects and relevant technologies.

### 3. What role did context play in improving the result?

Context transformed a generic roadmap into a targeted and actionable learning plan. It helped the AI generate recommendations based on my background, goals, and available time.

## Key Learning

The more relevant context we provide to AI, the more accurate, personalized, and useful the output becomes.
